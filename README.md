# bgt-share

A static page for Board Game Tracker share links: `https://codetrollz.github.io/bgt-share/#g=<code>` (game) or `#p=<code>` (play).

The page reads the code from the part after `#` (never sent to a server) and opens the app with `boardgametracker://game?d=<code>` or `://play?d=<code>`. It stores nothing and has no analytics.
